# ILKW Renewal

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages deployment

Changes pushed to the `main` branch are automatically built and deployed.

Before the first deployment, open the GitHub repository's
**Settings > Pages > Build and deployment** and set **Source** to
**GitHub Actions**.
